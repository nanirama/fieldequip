# Core Web Vitals Optimization Checklist

## LCP
- Use next/image
- Preload hero images
- Reduce server response time

## CLS
- Always set width/height
- Avoid layout shifts
- Use aspect-ratio

## INP
- Reduce JS
- Avoid heavy client components
- Optimize event handlers

## General
- Use Server Components
- Use caching
- Minimize bundle size
